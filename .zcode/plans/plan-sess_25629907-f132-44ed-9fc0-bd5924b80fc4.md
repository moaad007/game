## A. Level system (replaces Endless Practice)

**Structure:** Level = 10 rounds, 3 hearts, no countdown timer. Clear all 10 rounds with hearts left → level complete → next level unlocks (persisted in localStorage `bec-level`, try/catch like existing `bec-night`).

**Difficulty ramp per level L:**
- Mole stay-time: `clamp(13 − (L−1)·0.55, 7, 13)` + existing length term
- Moles per round: 3, becoming 4 at L4+ when the grid has ≥3 columns (not portrait 2-col)
- Sentence pool: sorted by length; higher levels draw from progressively longer sentence windows
- Pop stagger: `i·0.5s` shrinking to `i·0.25s`

**Round flow (level mode):**
- Correct whack → progress +1, next round (existing 0.55s gap)
- Wrong whack → −1 heart, −5 score, REVEAL the correct mole (green pulsing ring + card stamped "Correct ✓" for 0.7s), then next round. 0 hearts → "Out of Hearts!" fail screen with Retry Level
- Timeout → existing toast names the correct sentence, no heart lost, fresh round (progress unchanged)
